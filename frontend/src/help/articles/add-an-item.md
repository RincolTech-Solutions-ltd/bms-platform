Add an item inside its category. The app gives it the next code of the category, such as BLB-0001. You never type a code.

1. Open **Items and categories**, then **Categories**, and tap **Open** on the item's category.
   ![Open the category](add-an-item-1.webp)
2. Tap **Add an item**. Type the name, what it is counted in and the price. The category is already chosen.
   ![Type the name, unit and price](add-an-item-2.webp)
3. Save it. The item code shows on the item, made by the app. It never changes, even if you move the item to another category.
   ![The item code made by the app](add-an-item-3.webp)

> You can also tap **Add an item** on the Items page. Pick the category first.
